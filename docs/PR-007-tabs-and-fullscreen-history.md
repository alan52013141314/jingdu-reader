# PR-007 多分頁與全畫面版本對比

2026-11-05；狀態：實作及驗證完成，準備發布。

## 需求
- 下一處差異以具體文字變更為單位，直接定位並短暫閃亮，不再要求使用者選區塊。
- 顯示換行及新舊空白行的變更。TXT不保存按鍵來源，Enter與Shift+Enter統一以↵標示；空白行標示「空白行」。
- 版本管理使用全域外觀設定，改為佔滿程式內容區的頂層頁面；必須退出版本管理才可操作閱讀／寫作。
- 支援多分頁，各文件的閱讀／寫作模式、位置、內容、保存流程獨立；外觀設定全域共用。
- 恢復全部分頁、模式及位置；關閉寫作分頁保存並依重複上限建立版本。差異定位後短暫閃亮並保留選中底色。

## 工作計劃
1. 對比資料模型：全文依序對齊變更，產生可定位的差異項目及新舊位置；可視化換行／空行，維持大文件有界顯示。
2. 版本管理全畫面及外觀：主介面不處理輸入，提供明確退出、前後差異、序號與目前差異高亮／閃動。
3. 多分頁：拆出獨立文件狀態、切換／新增／關閉，保存與錯誤互不影響；避免同一文件重複寫入。
4. 保存及恢復：按確認方案保存分頁列表、模式、位置，所有背景寫作分頁仍按全域間隔更新草稿。
5. 測試：逐處差異定位、多處增刪、換行與空白行、跨原文字塊對齊；分頁隔離、關閉保存失敗、重啟恢復；大文件性能及GUI測試，編譯發布。

## 邊界
不建立伺服器，不更改原TXT以加入顯示符號，不自動刪除舊版本。公開發布不包含私人文件、歷史或閱讀設定。

目前下一步：完成新版release編譯與公開發布。


## 驗證結果
- 27項 release 測試通過：包括全文多處修改、換行／空白行、重複段落對齊、UTF-8定位及既有120MB閱讀／大文件保存回歸。
- 多分頁整合測試直接驅動主程式更新：閱讀／寫作隔離、背景草稿、不重複開同一文件、重啟恢復模式與位置、關閉最後分頁不再恢復舊文件、寫入失敗保留文件，以及關閉全部分頁前保存所有寫作內容。
- 實際Windows GUI：兩分頁各為寫作／閱讀、夜讀全畫面版本管理、三處差異計數及第一／第二處定位、第二處新增空白行兩側閃亮與缺文標記、退出返回寫作、切到閱讀分頁，全部通過。關閉時非當前寫作分頁建立版本，狀態檔保留兩分頁與目前閱讀分頁。
- 舊模式切換與草稿生命週期保留；已知邊界是大量替換採連續範圍表示，對比視圖只排版目前差異的上下文。公開倉庫排除私人內容與驗證文件。
