# PR-006 具體差異及重複版本限制
2026-11-05

需求：版本對比突出實際增刪字元，保留共同文字正常顏色。連續相同內容最多原版本及一次重複；既有歷史不自動刪除。

計劃：
1. 儲存回歸測試：連按 Ctrl+S／關閉、重啟與內容修改後再次保存。
2. 對比改為 Unicode 字元差異，刪除紅底及刪除線、新增綠底；大區塊控制計算上限，快取當前區塊結果。
3. 測試多處修改、中文與 emoji、只增／刪、相同文字及大型輸入。
4. 編譯獨立新版 EXE，公開更新。

原因：舊版整塊使用單一顏色，並無字元級差異；舊保存規則無條件新增版本節點。

驗證：舊保存測試連存5次得到5節點（預期2）確實失敗；修正後21項release測試通過，包括舊歷史相容及相同文字不同分塊去重。字元差異測試檢查多點變更、Unicode、實際LayoutJob刪除線、空文與大型輸入上限。新版仍依區塊位置配對，超過計算上限會明確提示範圍標示，不自動刪舊版本。
實際GUI驗證：僅新增文字綠底、共同文字原色；既有相同內容兩節點後Ctrl+S不再增加，狀態列顯示限制提示。
