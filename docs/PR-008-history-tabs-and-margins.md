# PR-008 版本列表／對比分頁及獨立留白

需求：全畫面版本管理分成版本列表與對比兩個分頁；對比分頁名稱為「檔名#A #B對比」。對比不繼承正文左右留白，在對比內獨立設定。

工作計劃：
1. 分開列表與對比視圖，比較時自動切換，切回列表保留比較結果及差異位置。
2. 新增對比專用左右留白，預設0，跨文件共用並保存；與正文留白及不留白完全分離。
3. 回歸測試設定保存及既有差異／多分頁流程，GUI檢查後編譯發布。

驗證：28項release測試通過。實際GUI確認版本列表與對比各自一頁、動態分頁名、比較後自動切換及切回列表保留結果。以正文左右各400px測試，對比仍預設0px且正常使用兩欄寬度。
