# PR-009 全文尋找、寫作章節定位與對比修正

2026-11-05。需求：移除空白行文字標記，保留換行符號；閱讀／寫作／版本模式支援Ctrl+F；修正寫作章名定位及保存後大量假差異。

證據：唯讀比對使用者小說版本1與3，788826與788824字元、換行數均31780，只有兩處單行修改。第3章存在於寫作第2區塊，而使用者當時選第3區塊。故沒有觀察到此章遺失，問題為區塊／章節導航不同與重複行配對。

計劃：先以合成測試鎖定重複分隔行對比；優先唯一行錨點、必要時才採重複行配對。增加寫作章節列表及閱讀位置映射。共用背景全文搜尋，可上一筆／下一筆與定位標示，版本搜尋涵蓋A/B全文。移除空白行文字，保留所有換行。測試、GUI驗證及編譯發布。使用者文件及歷史只讀，不改寫、不上傳。

驗證：32項公開合成測試；另以本機私人版本1／3驗證新版對比為2處差異，私人fixture與臨時測試均不提交。實際GUI驗證閱讀Ctrl+F定位及標示、切寫作定位同章、寫作搜尋選中、版本A/B全文搜尋及黃色標示、空行文字移除。使用者原始文件與歷史未修改。
