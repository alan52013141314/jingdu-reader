# PR-003 全域閱讀設定與左右留白

需求：正文左、右留白可分別調整；所有外觀與操作設定共用全域設定，每本書只獨立保存閱讀位置。

計劃：增加0–500 px左右留白，在窄視窗自動縮小以維持可讀寬度；移除正文1100 px固定上限，使兩側留白決定正文寬度。調整留白保留文字錨點。遷移舊紀錄時，以最後閱讀書籍外觀作為全域初始值。回歸驗證後編譯並更新公開版本。

完成驗證：8項測試通過，包含舊版遷移、全域設定優先、每書只儲存位置、左右留白獨立生效及窄視窗保護。120 MB索引0.235秒。GUI已檢查左100 px、右200 px的獨立邊界與全域控制列。產物版本0.3.0。

追加需求：行距與段落間距可獨立調整，均為全域設定。實作行距1.0–3.5倍、段落額外間距0–120 px；兩種隔行模式作快速預設。以排版後各行座標、字形與游標座標一致位移，確保段距調整不破壞閱讀錨點。

最終驗證：9項測試全部通過，含行距／段距獨立生效及游標幾何一致性；GUI確認1.8倍行距、60 px段距、左100 px與右200 px排版正確。120 MB讀取解碼索引0.209秒。
