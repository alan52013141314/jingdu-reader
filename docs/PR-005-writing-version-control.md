# PR-005 寫作模式及本機版本控制

2026-11-04。狀態：實作及驗證完成，準備發布。

## 已確認需求
- 初次啟動預設閱讀模式；模式切換按鈕在上方，記住選擇及最後寫作文件，重啟恢復。
- 可編輯目前TXT、新建、另存。Ctrl+S、儲存及關閉寫回文件並建立版本；沒有改動仍建立節點，相同內容去重。
- 自動儲存預設60秒，可調；只有寫作模式且有更改才執行。只更新一份恢復草稿，不覆蓋原文件、不建立版本。閱讀模式不自動保存小說內容。
- 版本列表、預覽、兩版本對比、還原、刪除。還原前先保存目前內容為版本。
- 歷史預設1 GiB提醒上限，可調；只提醒，不自動刪除。當前文件和草稿不算歷史用量。
- 固定上欄改為一行／盡量少行，外觀設定放展開面板；固定左欄貼齊左側。

## 工作計劃
1. 寫作儲存核心：分塊文字、壓縮內容去重、原子替換原檔／索引，草稿替換及未被版本引用的資料清理，容量計算。測試相同內容節點、草稿零版本、刪除共享資料及還原。
2. 寫作介面與生命週期：背景讀寫，分塊編輯避免大檔整本排版；Ctrl+S、新建／另存、重啟恢復；關閉時先等待手動保存成功，失敗保持開啟。
3. 歷史視窗：預覽、選擇兩版本、分塊定位差異、並排查看內容；還原前保存。長篇預覽採分塊，避免一次顯示整本。
4. 精簡工具欄、全域模式／間隔／提醒上限保存。既有閱讀器功能回歸。
5. 單元／整合測試、大檔性能及獨立GUI驗證，release編譯與公開版本更新。公開倉庫排除小說、草稿、歷史資料與閱讀紀錄。

## 範圍及空間策略
版本是本機歷史，不使用Git保存個人小說。相同文字塊以SHA-256識別、壓縮一次供多節點共用。每次自動儲存僅替換最新草稿引用，清除沒有草稿或歷史節點引用的物件；手動歷史只在明確刪除節點後回收資料。界面清楚顯示版本／草稿儲存位置與歷史用量。

內容與索引寫入都使用同目錄暫存檔再原子替換，避免中途失敗破壞既有文件。單一文件的大量貼上或極端長段落仍需分塊排版；不建立伺服器，不上傳使用者寫作內容。

## 驗證結果
- `cargo test --release --locked --offline`：18項通過，含既有閱讀回歸及7項寫作測試。
- 超過100 MB合成文件：開啟及兩次保存約2.7秒；修改一個文字塊僅新增一個物件，其他歷史內容共用。重複合成文字的壓縮率不代表一般小說。
- 實際Windows GUI：初始閱讀、固定單行工具欄及左側停靠、寫作輸入、5秒測試自動草稿（原檔不變且零節點）、Ctrl+S（第一版本）、關閉（第二版本）、重新啟動恢復模式／文件、兩版本並排差異，全部通過。使用獨立 verification/writing-ui 測試資料。
- 還原、刪除、草稿重啟及失敗保存由儲存核心自動測試覆蓋。
- 已知界線：寫作以區塊編輯，對比以區塊位置而非逐字；版本時間使用Unix秒。背景保存期間暫停編輯；歷史上限只提醒。無伺服器，私人內容與歷史不提交。
