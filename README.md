# 靜讀 · Jingdu Reader

Rust Windows 桌面 TXT 小說閱讀器及寫作工具。背景讀取與分章，僅排版畫面附近的文字區塊，支援超過100 MB的文件。無伺服器，不上傳閱讀內容。

## 使用

在 Releases 下載 `novel-reader.exe`，放在可寫入的資料夾，雙擊開啟。滑鼠移到視窗上緣顯示工具欄；「外觀／自存設定」開啟設定面板，左緣顯示書架與章節。可勾選「固定功能欄」。預設書架為 `C:\Cursor\Project\noveltest\books`；可選擇其他資料夾或開啟單一本TXT。

- 中文數字、阿拉伯數字章節、卷、回、序章、尾聲與英文 Chapter 自動辨識；章名搜尋與跳轉維持檔案順序。
- 正文連續上下捲動，跨章不停止；點選任何章節從章首開始，包含再次點選目前章節。
- 捲動強度可調 0.2–5倍。
- 紙張、夜讀、護眼綠、純白、灰霧配色，自訂背景與文字顏色。
- 小18／中24／大32／特大40 px，自訂12–96 px。
- 按段隔行／全部隔1行為快速預設；行距可調1.0–3.5倍、段落額外間距可調0–120 px，彼此獨立。只調整顯示，不修改TXT。
- 左右留白可獨立調整0–500 px；窄視窗按比例縮小留白，保留可讀寬度。「不留白」可全域覆蓋兩側數值，取消後恢復。固定工具欄仍保留必要寬度。
- 常駐標題顯示「檔名(目前章節)」，按畫面頂端位置更新。
- 底欄顯示「已讀字數 / 全文字數 · 百分比」，以畫面底端位置計算；含標點及Unicode字元，不含空白。向上捲動時進度也會回退。
- 視窗、工作列與EXE使用內嵌的新月書本圖示。
- 字級、顏色、隔行、行距、段落間距、捲動強度、左右留白與功能欄固定狀態皆為全域設定，所有書共用。每本書只獨立保存閱讀位置。定時及關閉時保存，下次開啟自動續讀最後一本。
- 升級舊版紀錄時，取最後閱讀書籍的外觀作為全域初始設定，保留每本書的位置。

紀錄位於 EXE 旁的 `reader-state.json`，內含本機書籍路徑與閱讀設定，請勿公開。此儲存庫不包含小說、閱讀紀錄或下載器資料。移動 EXE 時，一起搬移該JSON才會帶走紀錄。閱讀過程請勿同時執行多個使用同一紀錄檔的實例。

支援 UTF-8 與有 BOM 的 UTF-16 LE/BE。分章是標題規則辨識，特殊格式可能需要以連續捲動閱讀；不提供全文搜尋。正文保留在記憶體，記憶體需求隨檔案大小增加。

## 寫作與版本控制（v0.5）

初次開啟是閱讀模式。上欄按「寫作模式」可編輯目前 TXT，也可新建或另存；程式會記住模式、最後寫作文件及區塊位置。固定上欄採精簡排列，左欄貼齊左側。

- **Ctrl+S／儲存／寫作模式關閉視窗**：寫回原 TXT 並建立版本。連續相同內容最多保留原版本加一次重複，超過則不新增節點；相同內容共用壓縮資料。儲存失敗保持視窗開啟並顯示錯誤。
- **自動儲存**：預設 60 秒，可調 5–3600 秒；有修改才更新一份恢復草稿，不寫回 TXT、不新增版本。重啟寫作模式時優先恢復草稿。切回閱讀或切換文件前也保留修改為草稿；閱讀模式不自動保存小說內容。
- **版本**：選擇 A、B 後按「比較 A / B」，並排顯示兩版內容，刪除字元使用紅底刪除線，新增字元使用綠底，共同文字保持原色；可跳到下一個不同區塊。亦可單版預覽、還原、確認刪除。還原先建立目前內容的備份，再建立還原版本。
- **大文件**：分塊編輯，每塊約 3,000–4,000 字元，可用左欄或上一塊／下一塊切換。區塊界線不會插入換行；保存按原順序接合。對比依區塊位置配對，再在區塊內逐字標示；極端大差異超過計算上限時提示並標示變更範圍，不提供自動合併。文件載入、儲存、版本解壓在背景進行，進行時暫停編輯，避免保存競爭。
- **空間**：SHA-256 識別文字塊，壓縮後共用；只保留最新自動草稿，清除不再被草稿或版本引用的內容。歷史預設每本 1 GiB 提醒，可調；**只提醒，不限制繼續保存，也不自動刪歷史**。目前 TXT 與草稿獨有內容不計入歷史用量；歷史用量包括共用內容及版本索引。大量版本仍會累積索引與變更內容，請在版本視窗手動清理。

寫作資料在 EXE 旁 `writing-data/`，以文件完整路徑區分。搬移程式時請一起帶走 `reader-state.json` 和整個 `writing-data/`；改名或移動 TXT 會視為另一文件。這些資料含私人作品，不應公開。原 TXT 仍保存原編碼（UTF-8、BOM UTF-8／UTF-16）及既有換行；編輯區輸入的新換行為 LF。版本不是異地備份，磁碟故障仍需另外的備份。

實作需求與驗證：[PR-005](docs/PR-005-writing-version-control.md)。

## 編譯與測試

```powershell
cargo test --release --locked
cargo build --release --locked
```

產物：`target/release/novel-reader.exe`。Windows 使用系統微軟正黑體；不隨程式散布字體。編譯需要 Windows SDK 的 rc.exe，以內嵌 assets/icon.ico。

測試涵蓋：120 MB實體TXT、Unicode分頁完整性、編碼、原檔章節順序、跨區塊捲動、章首上下邊界、文字位置錨點與設定原子替換。大型測試會在 `verification/` 建立可重現的合成資料。

本機120,002,732 bytes測試檔的讀取、解碼與索引約0.2–0.3秒；實際速度取決於硬體、磁碟、編碼及內容。正文每個區塊最多2,400字元，只有畫面附近的區塊參與排版。

寫作測試涵蓋：單一草稿回收、相同內容版本去重、還原前備份、刪除共享物件、UTF-16 寫回、寫入失敗恢復、新建文件重啟識別、關閉等待背景保存，以及超過100 MB的兩次保存。21項測試通過；實際 GUI 驗證閱讀預設、模式切換、自動草稿不改原檔、Ctrl+S、關閉版本、重啟續寫與 A/B 對比。
